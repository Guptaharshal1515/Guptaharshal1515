## `whoami`

I’m **Harshal Gupta**, a B.Tech Computer Science student specializing in **Cyber Security, Artificial Intelligence, and IT** at **Rashtriya Raksha University**.

I’m interested in understanding how systems behave, finding weaknesses in authorized environments, and building practical tools that turn technical data into useful security insights. My current interests include application security, SOC/SIEM, threat analysis, network security, and AI-assisted automation.

```text
FOCUS       Security engineering · Threat analysis · Practical automation
APPROACH    Research → Build → Test → Document → Improve
PRINCIPLE   Authorized testing. Evidence over assumptions.
```

## `areas of interest`

- **Application & Network Security** — web security, reconnaissance, vulnerability analysis, and network tooling.
- **SOC & Security Investigation** — SIEM, log analysis, alert triage, and incident response workflows.
- **AI-Assisted Security** — using AI to support evidence analysis, repetitive tasks, and structured reporting.
- **Systems & Automation** — Linux, Python, and repeatable technical workflows.

## `selected work`

### [HoneyScope](https://github.com/Guptaharshal1515/HoneyScope)
**Adaptive Web Application Honeypot · SIEM Integration · AI-Assisted Attack Analysis**

A security research project built during the IIT Jammu Summer School 2026 internship. It combines a web honeypot and SSH deception with Wazuh monitoring, MITRE ATT&CK mapping, and AI-assisted analysis to help organize security events into structured investigation reports.

> Project recognition: selected as the only project out of 60, leading to an offer to extend the internship.
