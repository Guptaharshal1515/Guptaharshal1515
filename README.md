## `selected work`

### [HoneyScope](https://github.com/Guptaharshal1515/HoneyScope)
**Adaptive Web Application Honeypot · SIEM Integration · AI-Assisted Attack Analysis**

Built during the IIT Jammu Summer School 2026 internship. HoneyScope combines web and SSH deception, Wazuh monitoring, MITRE ATT&CK mapping, and AI-assisted analysis to organize security events into structured investigation reports.

> **Recognition:** The project was selected as the only one out of 60 projects, leading to an offer to extend the internship.
